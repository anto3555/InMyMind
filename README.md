# In My Mind

Created by **Antonella**, a student from Peru.

In My Mind is an initiative that uses art and animation to invite people to see the world from different perspectives. It began with Antonella's school animation project about autism and continues here as a bilingual website with her story, characters, sketches, and interactive scenes.

## Creator and credits

- Original idea, research, writing, characters, storyboards, and animation: **Antonella**.
- Website direction and content: **Antonella**.
- Website implementation: created with Antonella through vibe coding with **Codex**.

## View the website

Open `index.html` in a browser. The site is static and has no installation step. The embedded animation loads from YouTube, so it needs an internet connection.

## Put it on GitHub

1. Create a new GitHub repository under the account that should own the project. Choose **private** if you do not want the site and personal story visible to everyone yet.
2. Unzip this package. Upload the **contents** of the `in-my-mind-github` folder to the repository root, including the `assets` folder. Do not upload the ZIP alone if you want GitHub to show the files.
3. Commit the files. GitHub displays the commit author from the account and Git settings used for the commit. The website and this README identify Antonella as the project's creator.
4. If you want a public website through GitHub Pages, make the repository public, then choose **Settings → Pages → Deploy from a branch → main → / (root)**.

The original report and poem PDFs are not part of this package. Selected project images that appear on the website are included in `assets`.
